# Combine 3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the Fantasy Draft Combine broadcast from "animated shapes on a field" to "watching NFL Network combine coverage": 60fps motion, per-drill realism, distinct sets, a persistent jumbotron scoreboard, and a seeded comedy layer (cold-open intros, walk-up nicknames, elimination roasts) — while keeping the whole show a pure deterministic function of (outcomes, elapsed).

**Architecture:** All new show content (cold open, jokes, scoreboard data, transition timing, choreography beats) lives in pure lib functions derived from the room seed via `createRng`/`seededShuffle`, feeding the existing `stateAt(outcomes, elapsedMs)` pipeline. Rendering stays in `components/scene/*`, routed by `Broadcast.tsx`. Animation moves from a 100ms interval to a requestAnimationFrame clock; positions are computed per frame from elapsed (no CSS-transition crutches for travel).

**Tech Stack:** Next.js 16.2.12 (App Router), React 19, Tailwind 4, vitest 4. No new dependencies.

## Global Constraints

Every task implicitly includes these. Copy of spec-level rules:

- The whole show remains a **pure deterministic function of (outcomes, seed, elapsed time)**; all viewers stay frame-synced.
- All randomness (including jokes) derives from the room seed via `createRng` / `seededShuffle` — **never `Math.random`** outside pure UI sparkle (Confetti is the only existing exception).
- **`Date.now()` is never read during render** — only inside effects/rAF callbacks (existing Broadcast convention).
- Quality gates on every commit: `npm run lint` (0 errors 0 warnings), `npm test`, `npm run build`.
- Pacing stays ~6–8 minutes for 12 managers; hard cap **≤ 8.5 min** (locked by a test in Task 2). Current show is ~7.4 min; the ~35.5s cold open brings it to ~8.03 min — no phase trimming needed.
- Jokes are **G-rated ribbing about fantasy football habits**, never about the real person beyond their name. No pronouns in joke templates (names only).
- The cold-open walk-up order **MUST be athlete index order (0..n-1), never `outcomes.order`** — pick order is the show's secret; revealing it in the open spoils the draft.
- Keep replay mode, sound (opt-in whistle/crowd/horn), lobby, fairness verification, and the control page working untouched unless a change is required by the spec.
- Engagement is a first-class goal (user directive): every scene should have a suspense beat, a payoff beat, and broadcast-style punch (stamps, flashes, crowd reactions) — not just correct geometry.
- Work on branch `combine-v3` (in-place, matching prior ledger convention). **Do not push to `main` until the final task** — pushing main auto-deploys production.
- Per AGENTS.md: this Next.js version has breaking changes; consult `node_modules/next/dist/docs/` before using unfamiliar Next APIs (tasks here stay within already-used APIs).
- Existing signatures you may consume (do not break): `createRng(seed): () => number`, `seededShuffle(items, seed, label)`, `stateAt(outcomes, elapsedMs)`, `lockedPicks(outcomes, elapsedMs)`, `EVENT_META`, `finishTimesMs(ranking, runDurationMs)`, `EventFrame`'s `renderTurn(ctx)` contract, `Athlete` props, `sound.{whistle,pop,horn,lock,swell,enable,disable}`.

export function athleteBios(seed: string, n: number): AthleteBio[] {
  const nicks = seededShuffle(NICKNAMES, seed, 'joke:nick');
  const colleges = seededShuffle(COLLEGES, seed, 'joke:college');
  return Array.from({ length: n }, (_, i) => {

- [ ] **Step 1: Implement `lib/useAnimationNow.ts`**

```ts
'use client';
import { useEffect, useState } from 'react';

/** Re-renders every animation frame with a render-safe Date.now() snapshot.
 * Replaces the old 100ms interval so motion is 60fps-fluid; determinism is
 * preserved because everything on screen is still a pure function of the
 * elapsed time this returns. */
export function useAnimationNow(): number {
  const [now, setNow] = useState(() => Date.now());
  useEffect(() => {
    let raf = 0;
    const loop = () => { setNow(Date.now()); raf = requestAnimationFrame(loop); };
    raf = requestAnimationFrame(loop);
    return () => cancelAnimationFrame(raf);
  }, []);
  return now;
}
```
